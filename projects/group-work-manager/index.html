The idea

The website brings the organisation of a group assignment into one place: members, tasks, meetings, documents and personal reminders. We developed it for the ESIN curricular unit as a team of three: Ana Carolina Alves, Bernardo Justiça Godinho and Maria Rocha.

My contribution

I contributed to the website and used SQL to work with the application’s data. The project gave me practical experience connecting forms and page views to a relational database, within a shared team implementation.

A group’s workflow

A user registers, creates a group and adds other registered members by email. Tasks appear in Not Started, In Progress and Done columns, with deadlines and priorities. Meetings include a time, a place or online link, and attendance responses.

Documents can be associated with tasks, and the application stores group notifications when new tasks, meetings or documents are created. Personal reminders are separate from group activities. The interface is rendered in PHP using shared templates and responsive CSS.

Connecting the data

The SQLite schema models users, groups, group roles, tasks, meetings, documents, notifications, reminders and attendance. GroupRole connects users to groups, while Attendance connects users to meetings. Creating a group also creates its leader membership within a transaction.

Page entry points load query helpers and templates; form submissions go to PHP action handlers that use PDO prepared statements. This separation makes it possible to follow a user action from the interface to its stored record and back to the page.
