The idea

NeuroFlow explores how physiological signals can become immediate feedback in a desktop application. EEG from a Muse S headband drives meditation and focus experiences: adaptive nature videos, a visual state indicator, focus monitoring and an optional Unity game.

The application also records sessions locally, allowing users to revisit predictions, band-power trends and signal plots alongside session notes.

My contribution

I contributed to the classification model and desktop application, including the connection between EEG predictions and the videos shown to the user. This linked offline model development with the practical demands of calibration, incoming signal quality and stable feedback.

Signals & models

The Python application receives EEG through Lab Streaming Layer. A background worker handles four channels, filtering, calibration and features while the PyQt5 interface remains separate. Signal-quality checks use movement information when available, together with contact and spectral indicators.

The offline pipeline extracts band powers, ratios, spatial differences, spectral statistics and temporal changes from six-second windows. It compares random forest, XGBoost, gradient boosting, an RBF SVM and an MLP using leave-one-subject-out cross-validation.

The labelled training conditions are concentrating, neutral and relaxed. The desktop combines model output with band powers relative to a personal baseline, then smooths the resulting feedback levels. The interface’s tense or distracted descriptions are derived feedback states.

Making predictions usable

A nominal 20-second calibration establishes the baseline. During a session, the worker processes updates every second and the interface responds through a feedback indicator and video scenes such as forest, beach and waterfall. A minimum interval between scene changes helps avoid constant switching.

OpenCV handles video playback. An OSC connection sends feedback to the optional Unity experience, while SQLite stores session information for later review. Replay utilities support development without an active headset connection.

Evaluation & lessons

The saved gradient-boosting metadata reports mean held-out-subject accuracy of 0.8464 and macro F1 of 0.8466, with an F1 standard deviation of 0.0724. These are recorded offline experiment results, not measured accuracy of the complete live application.

The repository contains several experiment versions with different parameters and results. The README keeps those records separate. It also identifies differences between offline and live filtering and distinguishes grouped cross-validation from in-sample session summaries.

The main engineering lesson was that a useful feedback experience requires more than a classifier: signal quality, calibration, feature consistency and smooth transitions all affect what the user sees. The prototype does not establish clinical mental-state recognition or therapeutic benefit.
