My contribution

During my curricular internship, I built a Python desktop application to use an existing deep-learning computer-vision model with images from an endoscopy camera. The application was designed to identify gastric cancer in the camera feed during an examination.

Model integration

The model depended on an older version of Python that could not share the application's Python environment. I used Docker to run it separately while integrating its predictions into the desktop app. My work focused on the application and model integration.
